# 事实核验与证据标准

## 核验目标

正式旁白中的历史、文化、地理、科学、生活实践、安全、统计和医学法律信息都必须能回溯到证据。创作直觉、模型记忆、未署名转载和同一来源的重复转载不能单独证明事实。

核验需要回答：主张原句是什么、风险有多高、由哪些来源支持、来源是否独立、是否与正文时间轴关联、是否仍有未解决冲突。

## 来源层级

优先使用：

1. 原始文献、法律文本、标准、档案、遗址或机构第一手说明。
2. 政府、公立博物馆、大学、学会、专业机构等官方或学术来源。
3. 有编辑责任和可追溯作者、日期、方法的权威媒体或专业出版物。
4. 用户提供的采访、地方资料或口述材料。它们可帮助定位问题，但在涉及高风险主张时必须寻找独立佐证。

来源必须记录标题、发布者、作者、日期、链接或稳定标识。不得把搜索摘要、无日期短视频、匿名帖子或二手摘录作为唯一证据。

## 可靠度与状态

每条证据写入：

- `reliability`：`high`、`medium` 或 `low`。
- `status`：`verified`、`partial`、`unverified` 或 `disputed`。
- `supports`：它具体支持主张的哪一部分，不能只写“有参考价值”。

`low` 证据不能把事实主张标为已核验；`partial`、`unverified` 或 `disputed` 证据不能支撑正式旁白中的确定结论。

## 风险分级

- `low`：一般性、无争议、不会造成实质误导的说明。
- `medium`：文化解释、地理关系、实践经验、来源可能随地区变化的规则。
- `high`：历史归因、数字统计、宗教或民族信息、政策法律、健康安全、个体风险、争议事件。

已核验的低风险主张至少需要一条 `high` 或 `medium` 证据。中风险主张优先使用 `high`；只有 `medium` 时至少需要两条独立来源。高风险主张至少需要两条证据，其中至少一条为 `high`。

医疗、法律和个体安全主张一律按 `high` 风险处理，至少需要两条高可靠度来源，并优先采用政府、专业机构、学术或原始文本。仍不得给出个体诊断、停药或加药、具体处方、保证诉讼结果或规避法律的操作建议。

## 主张与正文映射

`claims` 中每条主张都要：

- 使用唯一编号，例如 `C1`。
- 写出可直接核验的短句，不写成模糊主题。
- 关联一个或多个 `segment_ids`。
- 关联一个或多个 `evidence_ids`。
- 标记 `risk_level`、`category` 和 `verification_status`。
- 记录仍存在的条件、争议或适用范围。

正文出现年份、数量、历史归因、政策规则、健康安全建议或统计比较时，应建立对应事实主张。纯氛围描写和画面观察可以不入事实表，但不能伪装成事实。

## 证据表交付

交付 CSV 时，一条“主张-证据”关系展开为一行，至少包含：

- 证据编号、事实编号、事实陈述和关联段落。
- 风险等级、事实类型和核验状态。
- 来源类型、来源标题、发布机构、作者和来源网址或标识。
- 发布日期、访问日期、可靠度和支持内容。
- 核验备注，包括不覆盖的边界。

同一来源支持多个事实时可重复出现，但必须保持证据编号和事实编号映射清晰。
