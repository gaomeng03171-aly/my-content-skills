# 输入契约与确认规则

## 必填输入

| 字段 | 规则 |
| --- | --- |
| `locations` | 至少一个地点；保留用户原始写法；按出现顺序记录 |
| `tone` | 一个清楚可执行的基调；不要同时承诺互相冲突的多个基调 |
| `duration_seconds` | 视频总时长；接受秒数或换算后的分钟数 |

缺少任一项时只询问缺失项。用户明确给出数值后不得自行改成另一时长。

## 可选输入

- 发布平台、受众、叙述人称和视频类型。
- 必须讲到的体验、季节、行程或文化信息。
- 不得出现的词、表达或内容。
- 参考样本。参考样本只用于提取结构和节奏，不作为事实来源。

## 冲突处理

- 用户地点与资料地点不一致：保留用户地点，单独列出冲突。
- 情感基调与内容不匹配：先说明冲突并给出可选处理，不静默改写基调。
- 目标时长与预期信息量冲突：优先保留用户时长，通过删减分支或拆分系列解决。
- 精确时长无法由字数保证：说明 210 至 260 个有效字符/分钟只是估算；只有实际配音或时码才能证明成片时长。

## 默认值

仅在用户没有指定且默认值不影响主题时使用：

- 受众：计划出行的普通旅行观众。
- 叙述人称：第二人称或克制的第一人称复数。
- 平台：通用短视频/宣传片。
- 版本：`V1.0`。
