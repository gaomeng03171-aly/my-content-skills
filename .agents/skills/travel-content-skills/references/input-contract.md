# 输入契约与确认规则

## 必填输入

| 字段 | 规则 |
| --- | --- |
| `topic` | 本集要回答、解释或呈现的核心主题；不能只是“介绍某地”一类空泛任务 |
| `domain` | `history_culture`、`geography_travel` 或 `life_skill` |
| `duration_seconds` | 本集视频总时长，接受秒数或换算后的分钟数 |
| `project_type` | `single` 或 `series` |

系列项目还必须提供 `series_title`、`episode_number`、`total_episodes` 和 `episode_title`。缺少必填项时只询问缺口，不提前撰写正文。

## 默认值

仅在用户没有指定且默认值不影响主题时使用：

- 受众：`中老年受众`。
- 叙述人称：清楚自然的第二人称，或克制的第三人称讲解。
- 平台：通用视频/电视播出。
- 语气：平实、温暖、清楚。
- 版本：`V1.0`。

## 可选输入

- 地点、人物、物件、时期、行动步骤或必须回答的问题。
- 既有资料、参考链接、采访稿、地方志或用户口述。
- 禁用表达、必须保留的信息、画面限制和配音约束。
- 系列项目的先后关系、前集回扣和后续预告。

参考样本只用于提炼结构和节奏，不能作为事实来源。

## 适用性判断

- 简单换写、广告口号、营销卖点堆叠和没有完整内容目标的短片不使用本技能。
- 未经核验的医疗、法律或个体安全建议不进入正式文稿。
- 已由权威资料支持的通识性健康、安全或法律信息可以说明，但必须保留来源边界，不给出个体决定或替代专业人士的建议。
- 历史争议、民族、宗教、政策、统计数字和人物经历只有在证据充分时才进入时间表；否则删除或明确说明资料不足。

## 冲突处理

- 用户主题与资料范围不一致：保留用户主题，列出无法核验的部分，不补造内容。
- 目标时长与信息量冲突：优先保留用户时长，通过删减分支或拆分系列解决。
- 系列集数冲突：先确认单集边界和总集数，不把未授权内容强行并入本集。
- 精确时长无法由字数保证：170 至 210 个有效字符/分钟只是估算；只有实际配音或剪辑时码才能证明成片时长。
